
# Student Result Analyzer

A responsive web application to manage student academic records,
calculate grades, and analyze academic performance.

## Features

- Student registration and management
- Add, edit, delete, and search student records
- Automatic total marks and percentage calculation
- Automatic grade and pass/fail determination
- Dashboard with academic statistics
- Grade distribution chart
- Subject-wise performance analysis
- Pass/fail visualization
- CSV export for student results
- Browser-based local storage
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser LocalStorage

## Grading System

| Percentage | Grade |
|---|---|
| 90–100 | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| 50–59.99 | D |
| Below 50 | E |
| Failed in any subject | F |

A student must score at least 35 marks in every subject to pass.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it in your browser.
4. Add student details and marks.
5. Explore the dashboard and analytics.

An internet connection is required to load the Chart.js library.

## Data Storage

Student records are saved in the browser's LocalStorage.
The data remains available in the same browser unless its
site data is cleared.

This is a frontend demonstration project, not a
multi-user production database.

## Deployment

The project can be hosted using GitHub Pages.

1. Push the project files to your GitHub repository.
2. Open the repository's Settings.
3. Navigate to Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for the deployment to complete.
